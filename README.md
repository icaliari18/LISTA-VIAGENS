Minha Lista de Viagens
/baseado na biblioteca feita em aula. lugares que quero visitar, país, ano da meta p ir e valor necessário p viajar/ 

- frontend: página HTML, estilos CSS e JavaScript do navegador.
- backend: servidor express, rotas, controller e conexão MySQL.
- sql: comando para criar o banco e a tabela com locais de exemplo.

- GET /locais: lista todos os locais.
- GET /locais/:id: busca um local pelo ID para preencher o formulário.
- POST /locais: cadastra um local.
- PUT /locais/:id: atualiza um local.
- DELETE /locais/:id: conclui o local, removendo-o da lista.
